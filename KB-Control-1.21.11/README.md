# KB Control (Fabric 1.21.11)

A small administrator-oriented configuration starter with:
- a static Vanilla JavaScript configuration dashboard;
- a Fabric server mod that loads and validates `config/knockback.json`;
- operator-only `/kb` commands to inspect, reload, and update configuration.

## Important scope
This starter manages settings only. It does **not** alter Minecraft knockback physics yet. The dashboard exports JSON; the mod reads its own server-side config. There is no remote browser-to-server connection.

## Requirements
- Minecraft Java Edition 1.21.11
- JDK 21
- Fabric Loader and Fabric API for 1.21.11
- Gradle (or import this project into IntelliJ IDEA)

Fabric's 1.21.11 docs specify JDK 21. The official reference currently lists Fabric API `0.141.1+1.21.11`.

## Build
1. Open `gradle.properties`.
2. Set `loom_version` to the current stable Loom version shown by the official Fabric template generator for Minecraft 1.21.11. Loom releases change independently, so this starter deliberately does not guess a plugin release.
3. Run `gradle build` from this directory (or use the Gradle wrapper generated by the official template).
4. The remapped mod JAR will be in `build/libs/`. Use the JAR without `-sources` or `-dev` in its name.

For the most reliable setup, generate a Fabric 1.21.11 project at https://fabricmc.net/develop/template/ and copy this project's source files and dependencies into that generated template. Keep the generated wrapper and Loom version.

## Install on your own server
1. Install Fabric Loader for Minecraft 1.21.11 on the server.
2. Put the built `kb-control-1.0.0.jar` in the server's `mods/` folder.
3. Also put the matching Fabric API JAR in `mods/`.
4. Start the server once to create `config/knockback.json`.
5. Use `/kb status`, `/kb reload`, or `/kb set ...` as an operator (permission level 2).

## Commands
- `/kb status`
- `/kb reload`
- `/kb set enabled true|false`
- `/kb set horizontal <0.1..2.0>`
- `/kb set vertical <0.1..2.0>`

## Web dashboard
Open `web/index.html` in a browser. Use Export JSON, then copy the downloaded `knockback.json` into the server's `config/` directory and run `/kb reload`.
